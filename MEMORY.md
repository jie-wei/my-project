# Project Memory

[LEARN:slides_style] Madrid styling or Open Sans body text → Use the [adapted Seminar Notes style](slides/README.md#visual-style): handwritten presentation titles and frame headings, with Latin Modern serif retained for all non-heading text and Latin Modern math.

[LEARN:slides] Generic slide-making defaults → Use the [theory-talk rules of thumb](slides/README.md#theory-talk-rules-of-thumb), adapted from Shengwu Li, for future presentations. Treat them as flexible guidance alongside our notation and communication preferences.

[LEARN:communication_style] Apply these preferences only to summaries, squeeze content together, or use flat proof lists → Apply them to chat and documents: one main idea per paragraph, visible spacing, and major proof steps whose sufficiency is explained before nested justifications. Keep separate pages in paginated research notes. See the [shared conventions](.agents/rules/standalone-conventions.md#research-reasoning).
