% Layout and proof structure:
%   - Setup holds PRIMITIVES ONLY (bulleted) + the maintained assumption.
%     Every other object is defined at the top of the section that first uses it.
%   - State a result's hypotheses and explain why its major proof steps suffice.
%   - Top-level bullets give the major steps and their roles. Nested bullets
%     justify them with assumptions, calculations, supporting results, and cases.
%   - Separate lemmas are optional. When useful, show their roles in the main
%     proof before presenting their statements and layered proofs.
%   - One main idea per paragraph or bullet, with visible spacing.
%   - Put justified align* chains under the steps they establish.
%   - Explicit summation bounds everywhere; argument-explicit functions in
%     statements; registered notation in statements, raw algebra in proofs.
%   - \clearpage before each section after the first; figures non-floating,
%     never alone on a page.
